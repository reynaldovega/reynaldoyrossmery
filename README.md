# Parte digital de matrimonio

Parte digital de matrimonio de Rossmery y Reynaldo.

## Publicacion en Render

1. Subir esta carpeta a un repositorio de GitHub.
2. En Render, crear un nuevo `Static Site`.
3. Conectar el repositorio.
4. Usar estos valores:
   - Build command: dejar vacio
   - Publish directory: `.`
5. Publicar.

El archivo `render.yaml` tambien permite crear el sitio desde Blueprint en Render.

## Dominio

Se puede usar el dominio gratuito de Render o conectar un dominio propio como:

- `rossmeryyreynaldo.com`
- `boda-rossmery-reynaldo.com`
- `reynaldoyrossmery.com`

Si se compra un dominio, se conecta desde la seccion de dominios personalizados de Render.
